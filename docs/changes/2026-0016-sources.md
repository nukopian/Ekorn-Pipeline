# 2026-0016. Sources that come with Perl

**Status:** in progress

**Decisions:** None of its own: the design's 8.2 (2026-0022's D67,
D68, D69) settles it.

**Origin:** roadmap, added 2026-11-10 from DBIx-Squirrel's grammar of
sources, stages, gathers and sinks, rewritten from the design approved
on 2026-11-13 (2026-0022)

**Depends on:** 2026-0021, shipped unreleased

**Started:** 2026-11-13

## Background

The design's 8.2 lists four sources, needing nothing beyond Perl, in
Ekorn::Pipeline::Sources, none exported by default: `from_array`,
`from_fh`, `from_file`, which takes I/O layers, and `counter`. The
prototype built `from_array` and `from_file`, the latter slurping
with `$/` undefined, an empty file giving none (D69). Its POD is a
placeholder.

## Decisions

None of its own. Two details the design leaves, taken as it implies:
`counter`'s start and step default to 1, as its "1, 2, 3 and on"
reads; and `from_fh` reads as `from_file` does, an empty handle
slurped giving none, croaking "Expected an open filehandle" for one
that isn't, as `dump_to` does.

## The plan

As the roadmap gave it on 2026-11-13:

> Ekorn::Pipeline::Sources, needing nothing from CPAN: `from_array`,
> `from_fh`, `from_file`, which takes I/O layers, and `counter`, as the
> design's 8.2 lists them; nothing exported by default. Built so far:
> `from_array` and `from_file`. Done when each is in, with its POD,
> tests and docs, and coverage above the floors.

Steps: `from_fh` and `counter`; tests for each source; the module's
POD in full; the reference's Sources section, from the draft; the
how-to's recipes for reading a file, using `from_file`; Changes.
